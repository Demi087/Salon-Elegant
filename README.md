# Салон красоты Элегант - Программная реализация сайта

## Стек технологий
- Язык серверной логики: PHP 8.0+
- База данных: MySQL 5.7+ / MariaDB 10.4+
- Клиентская часть: HTML5, CSS3, JavaScript (Native ES6)
- Реализация без использования CMS
- Режим для слабовидящих: ГОСТ Р 52872-2012
- Разработка структуры и требований: ГОСТ 34.602-2020

## Порядок запуска в среде XAMPP / OpenServer
1. Скопируйте содержимое папки проекта в корневую директорию веб-сервера (например: C:/xampp/htdocs/salon/ или domains/salon/).
2. Запустите модули Apache и MySQL через панель управления XAMPP Control Panel.
3. Откройте phpMyAdmin в браузере (http://localhost/phpmyadmin/).
4. Создайте базу данных с именем salon_db с кодировкой utf8mb4_unicode_ci.
5. Импортируйте SQL-скрипт из файла sql/salon.sql.
6. Откройте в браузере адрес http://localhost/salon/ (или http://salon/).
